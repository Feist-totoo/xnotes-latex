# Paddle API 轻量版 v6

2026-11-13，`0.9.8-latex.6-paddle-lite`，versionCode 75。APK **52,354,430 字节（52.4 MB）**，相较 v5.1 的 1,013,105,865 字节缩小 **94.83%**。支持 Android 8.0+，包含 arm64-v8a 和 x86_64。

## 当前功能

保留原生白板、套索、分页笔记、无限画布、LaTeX 预览与编辑、可拖动和缩放的公式块、保留原笔迹、撤销与重做。套索选区不再自动运行本地 OCR，识别全部通过 Paddle 官方 AI Studio API，需联网。白板与 LaTeX 排版仍在平板上离线运行。

打开转换窗口后，可以配置 Access Token 并主动上传当前选区，也可以直接输入 LaTeX。Paddle 返回的源码需点击“使用 Paddle 结果”才进入编辑框，成功生成预览后才能插入。取消、超时和鉴权失败均不改变原笔迹或已有编辑。不会在打开窗口或保存配置时自动上传。

十个学科包继续提供符号、模板、校对提示及按当前公式推荐编辑辅助，仍可独立启停、卸载、恢复和通过 GitHub 更新。移除本地候选评分开关和相关显示；轻量版不使用包内的历史评分数据来改变 Paddle 结果。

## 移除内容

- GryphOne 编码器和解码器、GLM-OCR 解码器与视觉编码器：四份模型全部从 APK 移除。
- ONNX Runtime AAR、相关 JNI 库、GLM/llama.cpp JNI 与本地识别调度代码全部移除；CMake 不再构建或依赖 llama.cpp。
- 构建不再下载或检查本地 OCR 权重。Gradle 使用过滤后的独立资源目录，避免仍在开发机器上的历史权重进入 APK。
- 界面不再出现“离线识别”“精细复核”等不可用入口，网络失败时可重试或手动编辑 LaTeX。

旧完整版保留在 [v5.1 Release](https://github.com/Feist-totoo/xnotes-latex/releases/tag/v0.9.8-latex.5.1-full)，旧版及其源码标签继续保留；旧版版本号较低，不能直接覆盖降级。当前分支构建轻量版。

## 覆盖升级

沿用 `com.xnotes.latex.debug` 和之前的签名，直接覆盖安装，不需要卸载。启动时在后台清理已知旧版本的 OCR 模型缓存，仅删除应用私有 `no_backup` 中白名单目录里的已知模型文件及下载临时文件。未知内容、符号链接、笔记、画布、设置、API 配置、学科包均不在删除范围内；不递归扫描或删除用户笔记。

模拟器从 v5.1 覆盖升级成功，15 个既有笔记、画布、设置和学科包文件在升级前后 SHA-256 全部一致，已知旧模型缓存目录全部清理。真机数据应仍保留，但未进行三星平板实机测试。

## API 配置

圈选手写或公式图片，点 **∑** 打开转换窗口，再点 **Paddle API 设置**，填入从 [AI Studio](https://aistudio.baidu.com/account/accessToken) 获取的令牌。编辑已有公式块时直接修改 LaTeX，不显示识别入口。默认官方 API 地址和模型可保留；也支持官网提供的 `/layout-parsing` 专属服务地址。令牌在本机用 Android Keystore AES-GCM 加密，不进入备份或笔记。配置和请求协议沿用 [v5.1 API 接入说明](FORMULA_PADDLE.md#协议依据)。

识别会把当前选区上传至 AI Studio；不会上传整页笔记、笔记文件名、原始笔画轨迹或学科包。已发送的请求无法通过“停止等待”撤回。
