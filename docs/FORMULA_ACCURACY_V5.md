# v5 完整离线 APK：双引擎、十个学科包与实测限制

2026-11-12，`0.9.8-latex.5-full`，versionCode 73。[下载安装包与独立包](https://github.com/Feist-totoo/xnotes-latex/releases/tag/v0.9.8-latex.5-full)。完整指安装包自带所需模型与资源，**不是对一般本科手写公式准确率的达标声明**。继续标记 prerelease，不替换 v3 稳定渠道。

## 实际变化

原始笔画仍使用快速 GryphOne Q8；单张图片改回独立 GLM-OCR 路径，解决 v4 图片回退只识对 1/100 的问题。原始笔画也可主动“离线精细复核”，查看第二模型结果后手动采用，原来的手工编辑不会被复核覆盖。图片的裁剪、旋转、镜像在识别时冻结；支持保留原内容、插入可移动块、再次编辑与撤销。

GLM 解码器压到 Q4_K_M，视觉编码器保留 Q8_0；移除固定 llama.cpp 普通解码不使用的 NextN 辅助层，保留全部 16 个活动层。四份模型与全部十个包在 APK 内，平板首次断网安装后可直接使用，首次解包需要额外时间和存储。两套引擎由共同锁串行调度，切换前释放另一套；取消不提交内容，空闲 30 秒或内存压力时释放。

高数、线代 v3 包从真实训练标签生成符号序列先验，只在视觉分数接近的候选间选择。其他八个包仍是符号、模板与校对辅助，不宣称有独立识别模型。所有包可独立启停、卸载、本地恢复和导入；GitHub Release 只用于主动更新 / 下载，不接收笔迹。

## 同样本开发机基准

沿用 v3 保守 MathML 结构匹配，保留大小写、符号、上下标、分式、矩阵、向量和数学字体。忽略部分排版差异，不做求解或 CAS 等价判定。错误、无输出和不可解析参考均留在分母。可排版率、候选 oracle 与人工修改结果不算自动识别正确。

| 同一组真实手写 | v3 | v4 默认 | v5 默认 |
|---|---:|---:|---:|
| 原 MathWriting excerpt/test 100 条，原始笔画 | 33/100 | 48/100 | 48/100 |
| 原 UniMER-Test HWE 100–199，图片 | 56/100 | 1/100 | 56/100 |
| 原混合 200 条 | **89/200** | 49/200 | **104/200** |
| v4 高数、线代专项 200 条 | 60/200 | 116/200 | 117/200 |

本表使用开发机固定推理流程对照，Android 实际验证范围另列。混合集根据真实输入类型调用引擎，不按参考答案选择。图片集整式正确数恢复到 v3 的 56/100，其中修正 1 条、回退 1 条；量化不是逐样本无损保证。快速模型没有换权重，旧笔画结果不变。精细复核是可选第二结果，不把“两个模型任选一个正确”的 oracle 冒充默认准确率。

## 学科包消融与新的确认集

训练统计只来自 Google MathWriting HUMAN TRAIN：总计 229,864 条已用人类标签；高数 38,842 条、线代 8,859 条。学科包 v3 改用 `P(下一个符号 | 上一个符号)`，包括首尾符号，alpha=0.25、strength=0.01、maxVisualGap=0.03。高数 6,510 个稀疏计数，线代 2,907 个。参数只在原验证 160 条比较，随后固定，不用确认集答案改统计或参数。没有神经网络训练 / 微调。

| 样本集 | 关闭包评分 | 开启包评分 | 修正 / 回退 |
|---|---:|---:|---:|
| 原参数验证 160 条 | 141/160 | 142/160 | 1 / 0 |
| 原专项测试 200 条，现作回归 | 116/200 | 117/200 | 1 / 0 |
| 原确认 240 条，现作回归 | 201/240 | 202/240 | 1 / 0 |
| **新冻结官方 TEST 160 条** | **95/160** | **95/160** | **0 / 0** |

新集高数 49/80，向量 / 矩阵 46/80。已有四候选中最多包含 99 条正确答案，重排本身无法解决主要错误。旧集上的小收益不足以证明稳定泛化增益；新集没有增益。首次安装默认开启保守候选辅助，可关闭；升级保留用户已经明确关闭的设置。

新确认集在预测前固定，排除所有 v3/v4 用过的 ID，使用 SHA-256 确定顺序。来自官方 TEST，不再使用 v4 官方 VALID 剩余样本。由于此前测试后只剩 4 条未用的多列矩阵，新线代组包含向量记号；分布与旧矩阵组不同，**不能把旧 201/240 的 83.75% 宣传为总体准确率，也不能据新百分比推算回退**。学科标签是表达式规则，不是人工审核的本科课程覆盖。

逐条验证原 HUMAN InkML 标签、坐标和原文件 SHA-256。新 160 条全部在 Android 原生运行并验证输入像素哈希。经实际 `Stroke` 浮点存储和 `FormulaDraft` 后 5 条像素变化，全部重跑并合并，其余 155 条输入相同；最终依然 95/160。160 条 Android 包重排与公开 Python 规则逐条相同。另在实际 APK 检查旧集已知的矩阵缺列分隔符、积分式缺模长竖线两个案例：关闭评分错误，开启评分正确。这只是定向回归，不作为新增准确率。未使用字体合成样本充当真实手写，不把合成交互测试纳入准确率。

## 模型体积与转换

| 产物 | v3 | v5 |
|---|---:|---:|
| GLM 精细模型两文件 | 1,434,837,056 B | 908,104,800 B |
| 全部模型（v5 另有快速模型） | 1,434,837,056 B | 940,331,421 B |
| 完整 APK | 1,492,082,002 B | **1,013,056,713 B** |

完整 APK 比原 v3 缩小约 32.1%，但大于仅有快速模型的 v4 99.9 MB。不是把不同能力的包当成同体积比较。

固定 GLM-OCR 源版本 `65a42de1148dbed2297e922b5dbc7d9b70c36578`，llama.cpp `2d973636e292ee6f75fadcf08d29cb33511f509f`。原 Q8 解码器用上游量化工具转 Q4_K_M；最终视觉端保留原 Q8_0。先试验的 Q5_0 视觉权重在 Android 第一条固定公式上复用耗时 41.546 秒（v3 同公式 11.525 秒），瓶颈为视觉编码，因此拒绝这个更小但更慢的配置。初版 853 MB 候选 APK 没有发布，保留拒绝依据。NextN 移除前后 163 个保留张量逐字节一致，固定 5 条真实验证样本输出也一致。最终 Q4/Q8 配置在旧 MathWriting 图片验证 100 条得到 38/100（旧 Q8 37/100）；HWE 对照见前表。Q5 试验结果和终止原因独立保存，不混入最终包成绩。转换报告、精确哈希和失败输出均公开。

## Android 验证与性能

实际签名 APK 覆盖安装在 Android 14 x86_64、2 vCPU、4 GiB 模拟器。识别测试启用飞行模式，关闭 Wi-Fi / 移动数据；应用不访问识别服务器。单独的开发机图片评估使用本机进程，已在 Android 性能测量前关闭。三星 / S Pen 真机尚未验证。

2510 项 JVM 测试无失败。8 项 Android 工作流、裁剪与包迁移检查通过，覆盖套索、预览、手动纠错、插入、拖动、编辑、撤销、取消、无限画布、选区变化检查，以及十包首次离线安装与保留已有禁用 / 卸载设置。精细复核不会覆盖正在手改的 LaTeX。

另外固定抽取原 HWE 集的 20 条（100、105、…、195）走实际 Android 图片入口，20 条均完成，无引擎错误。Android 为 **8/20**，同 20 条开发机为 9/20；19 条结构输出相同，编号 135 的 Android 输出多了显式乘号，按既定严格指标仍计不匹配，不为新版本放宽规则。**开发机 104/200 不等于已在目标平板完整复测 200 条。** 新增原始笔画 160 条则已逐条在最终 APK 验证。

同一 Android 14、2 vCPU、4 GiB 模拟器，以三条固定真实笔迹（旧专项索引 0、100、199）分别做冷加载、复用、释放后重载。首次从 APK 解包不用于公平比较，跨运行的主机负载不能完全相同。原始结果见 [计时记录](benchmarks/v5/speed-summary.json)。

| 三条平均 | v3 GLM 主路径 | v5 快速笔画 | v5 按需精细复核 |
|---|---:|---:|---:|
| 复用模型耗时 | 10.254 s | **1.849 s** | 13.512 s |
| 释放后重载耗时 | 11.266 s | **1.917 s** | 14.687 s |
| 复用后进程 PSS 快照 | 1671.6 MiB | **403.1 MiB** | 1401.3 MiB |

快速路径相对旧 v3 主流程明显缩短等待；v4 同样本为 1.622 秒，本次没有证明快速模型进一步提速。精细引擎减小了体积与 PSS，但本轮**没有证明比 v3 更快**，因此按需调用，不自动拖慢每次笔画转换。PSS 是运行后快照，不是峰值；三条计时不代表全部公式，更不是三星平板的性能承诺。

最终 APK 共 16 项 Android 检查通过，包括上述工作流、160 条确认与浮点重跑、两条已知包修正回归、20 张图片入口、两引擎切换 / 取消、两引擎各九次计时，以及早期公开手写和本地私有截图的运行检查。另 12 张早期 MathWriting 公开图片仅 1/12 整式正确，失败输出同样公开。运行检查通过不表示每个公式识别正确；准确率独立计分。

合成 UI fixture 的 x=1 被快速模型读成 χ=1，精细模型读成 X=1，**均计为失败**。截图中的 x=2 是人为编辑，用于验证复核不覆盖文本；插入操作测试另人工改成 x=1，不属于识别成绩。私有用户截图仅作本地回归，不上传原图或完整私有输出。

## 发布、许可与复现

[使用和构建](FORMULA.md)：运行 `python tools/prepare_full_formula.py`、`python tools/package_formula_mods.py`，再 Gradle 构建。模型下载在开发机器发生；Android 使用 APK 内资源。模型、包有 SHA-256 校验；GitHub 包格式是有界数据，不能执行代码。

APK 为 `com.xnotes.latex.debug`、versionCode 73，沿用此 fork 原签名，支持 Android 8.0+ / arm64-v8a / x86_64。可覆盖旧 fork，建议直接安装升级，勿先卸载应用内笔记。完整模型和十个学科包均已内置；不需要下载“基础包”才能识别。

代码 AGPL-3.0；GryphOne、GLM-OCR、llama.cpp、ONNX Runtime 为 MIT，DINO 为 Apache-2.0。高数 / 线代统计资源由 Google LLC MathWriting 派生，**CC BY-NC-SA 4.0（署名、非商业、相同方式共享）**。原始笔迹、评测图片、私有截图不随主 APK 分发。详见各模型 NOTICE 与包内来源。

[公开结果与复现索引](benchmarks/v5/README.md) 保留全部分母、预测、指纹、转换报告和发布验证。通用物理、完整本科高数 / 线代课程题型没有专项覆盖证明；准确率仍是后续的主要限制。
